# Aplikasi Android Yayasan Al-Amin

Project Android Studio untuk membungkus portal `https://yayasan-alamin-almaarif.netlify.app/app.html` sebagai aplikasi resmi. Custom Tabs dipakai agar login Supabase dan Google OAuth tetap berjalan menggunakan browser/Chrome pengguna.

Buka folder `android-app` dengan Android Studio, tunggu Gradle sync, lalu Build > Build APK(s).
